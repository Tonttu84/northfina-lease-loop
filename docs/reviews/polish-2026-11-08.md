## 2. Security

**Verdict.** For a public demo URL the repo is in better shape than most hackathon code. Every API route answers through `handleRoute` / `fail` (no stack traces, no raw messages, Zod issues only); every private read and write asks the pure `can()` policy before touching a record and the services ask again; the meta rules pin the public-route allowlist; there is no raw SQL and no `dangerouslySetInnerHTML`; every state change is a same-origin `fetch` with a JSON body under `SameSite=Lax` HttpOnly cookies, so there is no practical CSRF; the signing tokens are 192-bit, single-use, 14-day, format-checked and stripped from GET responses; `.env` was never committed and no key-shaped string exists in any revision; secretlint runs in the pre-commit hook. The weaknesses are all consequences of D17 "no login": anyone is admin or any customer in one click, the demo clock is open to everyone and drives every date rule, the public audit log republishes whatever a visitor typed into the apply form, anonymous visitors can write quotes without limit, and there are no security headers. None of that needs a login. It needs the demo mode named, switchable and labelled, plus a day of hardening.

// Builds e2e.db once per run: the real migrations, then the data-pack seed, with the Prisma CLI
// exactly as `npm run db:setup` does. Specs empty and reseed it per test (e2e/fixtures.ts).
import { execFileSync } from 'node:child_process';
import { rm } from 'node:fs/promises';
import { createRequire } from 'node:module';
import path from 'node:path';

const DATABASE_URL = 'file:./e2e.db';

export default async function globalSetup() {
  const file = path.resolve('e2e.db');
  await Promise.all(
    [file, `${file}-journal`, `${file}.anchors.jsonl`].map((f) => rm(f, { force: true }))
  );
  const require = createRequire(import.meta.url);
  const prisma = path.join(path.dirname(require.resolve('prisma/package.json')), 'build/index.js');
  const env = { ...process.env, DATABASE_URL };
  execFileSync(process.execPath, [prisma, 'migrate', 'deploy'], { env, stdio: 'pipe' });
  execFileSync(process.execPath, [prisma, 'db', 'seed'], { env, stdio: 'pipe' });
}
